# Rule log

Every change to HEAR's question-mark rule, in the order tried. E1–E2 were tried on earlier recordings before the main experiment; 1–10 are the ten changes tested after it. "Fixed before test" means the rule and its numbers were written down before the test recordings were measured. Error score = (S? + w·S grey)/N statements + (Q. + w·Q grey)/N questions, checked at w = 0.25, 0.5 and 0.75.

**Starting rule (live).** A full "?" after Korean question endings (-니, -냐, -나요, -까요, -ㅂ니까 ...) or when the pitch rises 4 semitones or more at the end; no mark after statement endings (-ㅂ니다, -구나, -ㄹ게요 ...); a grey "?" when the sentence starts with a wh-word and the end rises 2–4 semitones. On the 30 main-experiment speakers (1,916 sentences, never used to set this rule): 97.2% of questions got a mark, 14.1% of statements got a full "?".

**Lesson from #4.** The rule-building and test speakers were different people but read the same sentences. After this, test sets used new sentences as well as new speakers.

**Exclusions decided before measuring.** Two speakers in set A and one in set C were excluded because their files could not be matched to the card order with confidence. Four spliced sentences from one main-experiment speaker were excluded.

**Re-check after going live.** The pushed site code was run again on sets B and C and gave the same numbers as above.
